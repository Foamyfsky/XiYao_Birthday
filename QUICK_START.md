## Customization Tips

### Change the Birthday Messages
Edit the `letterTexts` array in `app.js` to add your own messages.

### Change Photo Captions
Edit the `stages` array in `app.js` to customize chapter descriptions.

### Change Colors
Edit the `:root` section in `style.css` to modify the color palette.

### Add/Change Photos
Replace XiYao_*.png files with your own images (keep filenames the same).
