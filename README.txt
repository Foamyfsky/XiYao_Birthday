🎂 张曦瑶的21岁生日邮差 Birthday Memoir App
================================================

📖 QUICK START / 快速开始
Open index.html in your web browser to view the app.
在网络浏览器中打开 index.html 来查看应用。

✨ FEATURES / 功能
- Name validation: Only accepts 张曦瑶, 曦瑶, 瑶, or 小瑶
- Birthday song plays when correct name is entered
- Interactive story with 5 memory chapters
- Full photo gallery with hover effects
- Special effects: Petal rain, heart bursts, constellation display
- Taurus (♉) birthday constellation featured
- Warm, girly, sunshine aesthetic with early summer vibes

🎵 MUSIC & EFFECTS / 音乐和效果
- Birthday song plays automatically on name unlock
- Toggle music on/off with the music button
- Petal rain animation on each page transition
- Heart burst effect when clicking photos
- Constellation animation for Taurus

📁 FILE REQUIREMENTS / 文件要求
All files must be in the same folder:
- index.html (main HTML file)
- app.js (JavaScript logic)
- style.css (styling)
- XiYao_1.png through XiYao_25.png (25 photo files)

⚠️ IMPORTANT: All 25 images (XiYao_1.png - XiYao_25.png) must be present for the app to work correctly.

🌐 DEPLOYMENT OPTIONS / 部署选项

OPTION 1: GitHub Pages (RECOMMENDED for easy sharing)
-----------------------------------------
1. Create a GitHub account if you don't have one (github.com)
2. Create a new public repository named "XiYao-Birthday"
3. Upload all files (index.html, app.js, style.css, all XiYao_*.png images)
4. Go to Settings > Pages
5. Set Source to "main" branch
6. Your app will be available at: https://[your-username].github.io/XiYao-Birthday
7. Share this link with your friend!

OPTION 2: Netlify (Also easy, with auto-deployment)
-----------------------------------------
1. Go to netlify.com
2. Sign up for free
3. Drag and drop your folder (or connect GitHub)
4. Your app gets a live URL instantly
5. Free and works worldwide, including China

OPTION 3: Vercel
-----------------------------------------
1. Go to vercel.com
2. Sign up with GitHub or email
3. Import this project
4. Get instant live URL for sharing

OPTION 4: Local Network Sharing
-----------------------------------------
For sharing within local network only:
1. Make sure all files are in same folder
2. Open terminal/command prompt in that folder
3. Run: python -m http.server 8000
   (or: python3 -m http.server 8000 on Mac)
4. Open: http://localhost:8000 in browser
5. Share your computer's IP address with others on same WiFi

OPTION 5: Traditional Zip Download
-----------------------------------------
If recipient has all files locally:
1. Zip all files together (including all 25 images)
2. Send via WeChat, email, etc.
3. Recipient extracts and opens index.html in browser

📝 CUSTOMIZATION / 自定义
To modify the memories or messages:
1. Edit the "letterTexts" array in app.js to change messages
2. Edit the "stages" array to change chapter captions
3. Replace XiYao_*.png files with your own photos
4. Modify colors in :root section in style.css
