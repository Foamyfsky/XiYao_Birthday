# Accompanying Dog for Xiyao

A small interactive birthday webpage made for my friend Xiyao.

Happy birthday, Xiyao. Wish you happy birthday and pass your lawyer test.

## What The Webpage Does

- Opens with a birthday envelope.
- Shows a pixel forest cottage with an accompanying dog.
- Lets Xiyao type simple commands to interact with the dog, including rolling, jumping, spinning, running, sleeping, feeding, petting, showering, changing the sky, and turning the cottage lights on or off.
- Unlocks the cottage with Xiyao's name.
- Plays a birthday melody after the cottage is unlocked.
- Shows an indoor room with more dog interactions.
- Opens a photo album using `XiYao_1.png` through `XiYao_25.png`.
- Opens a letter from the books inside the room.

## What Has Been Done

- Built the page as a self-contained static webpage.
- Added the accompanying dog interactions in the forest and inside the room.
- Added the locked cottage flow.
- Added the birthday melody using browser audio.
- Added the album using the 25 local PNG images.
- Added responsive styling for desktop and mobile browsers.

## Files

- `index.html` - webpage structure.
- `style.css` - visual design and dog animations.
- `app.js` - interactions, unlock flow, audio, album rendering, and commands.
- `XiYao_1.png` to `XiYao_25.png` - album images used by the webpage.

Open `index.html` in a browser to use it.
